## ST VPN

Android VPN client, based on [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid) (GPL-3.0), using the [Clash.Meta](https://github.com/MetaCubeX/Clash.Meta) core.

### Requirement

- Android 5.0+ (minimum)
- Android 7.0+ (recommend)
- `armeabi-v7a`, `arm64-v8a`, `x86` or `x86_64` Architecture

### Build & install (USB)

```
./gradlew :app:installMetaRelease
```

### Package name

`com.stservice.stvpn`
